Introducing derekyt.dev version 1.1

August 14, 2026 • 09;12 UTC

Today, I'm releasing version 1.1 of my website, derekyt.dev. And it's huge.

This builds heavily on version 1.0 beta 1, but there's so many changes that it required a version bump. Let's dive in.

Homepage

First, let's kick off with the page you see first—the homepage. I've ditched the background images that used the WWDC26 pre-intro as a base. In both light and dark mode, they've been replaced by images I took myself earlier this year.

Perhaps the most obvious change on first visit is the lack of site release lists. I've removed these for a cleaner appearance, and they can be found here. Dedicated pages for each release are available.

Projects

The Projects page is getting a big upgrade in this version. Previously, button links to my projects and their respective releases were separate. Now, it's all in one element. From top to bottom: a project selector, project description, and links to the project and its release notes. Additonally, for Apple beta timelines, there's a link to try the version 2.0 beta.

Lastly, Projects gets updated background images, also ones I shot myself.

Releases

Apple beta timelines

Several Apple beta timelines versions have been added: 1.6.4, 1.6.5; Summer Update (1.7) beta 2, RC, and final build; 2.0 betas 1 and 2. Additionally, builds for version 1.5 are available. In the coming weeks, version 1.4 and prior will be added.

Preview: Additionally, CSS rules for Apple beta timelines release pages will be migrating to a universal style sheet within the next few weeks, and said pages will be switching their font from Inter to SF Pro. Inter will remain as a backup in case something goes wrong.

Lastly, the main releases page has received an updated background for iOS 27.

Android beta timelines

Preview: Just like Apple beta timelines release pages are switching to SF Pro, Android beta timelines release pages will soon switch to Google Sans Flex.

Android beta timelines version 1.0.3 has been added.

Compatibility charts

Preview: Compatibility charts will also move to SF Pro.

Assets

I've removed a couple dozen old assets that are no longer being used. Additionally, I've organized much of the remaining assets into folders.

Updates (the page)

The Updates page will soon be retired, in favor of a blog. I'm still planning it out, but what I do know is that the releases pages do Updates' job better, even if it's divided into many more pages. A deprecation notice has been put up to alert of the upcoming retirement.

Labels

The label about my site being in beta has been removed with this release, and temporarily replaced with a banner for this blog post.

So that's version 1.1. Enjoy!
